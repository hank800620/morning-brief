**對你的意義:** 三條即時行動：①立即啟動 Arm AGI CPU 授權費壓力測試（EPS $0.60 超預期確認，三情境更新）；②排入 Q2 與 OpenAI 技術對話，確認 AI 手機晶片計畫中 MTK 的協同設計 vs OEM 方案角色；③峰會前霍爾木茲危機疊加關稅談判，供應鏈三情境模型加入能源成本變數，5/16 前完成董事會通報版本。

**摘要:** OpenAI 5/5 發布 GPT-5.5 Instant，取代 GPT-5.3 成為 ChatGPT 預設模型。架構特點：深度整合 Codex agentic coding 引擎，運行於 NVIDIA GB200 NVL72 rack-scale 系統。主要增益領域：agentic coding、computer use、long-context knowledge work。Plus/Pro 用戶可存取過往對話、檔案、Gmail 作為個人化記憶源。官方定位：「最聰明且最直覺的模型，能自行承擔更多工作直至任務完成」。

**摘要:** OpenAI 正與 Qualcomm 及 MediaTek 聯合設計 AI 手機專用晶片，架構核心：輕量任務（情境感知、記憶管理、小模型）on-device 處理，複雜推論 cloud offload。MTK 2nm 首批旗艦 SoC 已完成 tape-out（2025 底），Qualcomm 2nm 方案目標 2026 底；供應商清單與規格預計 2026 底/2027 Q1 確定，2028 量產，年出貨目標 3–4 億支。定位：App 被 AI agent 取代的下一代智慧手機平台。
**Insight:** 這是本週戰略重量最高的訊號。MTK 被 OpenAI 點名為 AI 手機晶片夥伴，直接確認 on-device AI agent 是旗艦 SoC 的主戰場，而不是 2030 後的願景。關鍵決策：MTK 應在 Q2 內明確三件事：①在此三方計畫中的角色（深度協同設計 vs reference design 供應商）；②on-device agent 架構（memory management + context tracking NPU 路線圖）是否對齊 OpenAI 規格；③2nm SoC 的 AI agent workload benchmark 是否符合 2028 量產門檻。市場地位的上限由這三個問題決定。

### ⑥ ⭐⭐⭐ SEMI 執行長：東南亞半導體需建生態系非只建廠，人才與供應鏈協調是關鍵瓶頸
**摘要:** SEMI 執行長 Ajit Manocha 於 SEMICON Southeast Asia 2026 發表主題演講，強調東南亞半導體業正進入「多兆美元機遇」但成敗關鍵是生態系協調（材料、設備、設計服務、人才）而非單一建廠。越南、馬來西亞、印度吸引大量外資 fab 投資，但設計服務與材料生態系建立需 5–10 年，短期仍是瓶頸。
**Insight:** 對 MTK 而言，東南亞設計中心的擴張時程需與生態系成熟度對齊——短期（1–2 年）可擴大馬來西亞測試封裝據點；中期（3–5 年）評估越南設計中心可行性；長期（5 年+）印度高階設計人才生態具戰略意義。不要把 5–10 年的生態系建設押注在 2–3 年的供應鏈多元化時程上。
