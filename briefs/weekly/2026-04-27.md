## 3️⃣ 🔭 本週 5 條主軸線

### 主軸 1: Google Cloud Next '26 — Agentic AI 從概念升格為雲端基礎設施，$750M 嵌入諮詢體系搶企業落地
- **重要性:** ⭐⭐⭐⭐⭐
- **發生了什麼:** Google Cloud Next '26（4/22~24，拉斯維加斯）發布三件事：(a) Vertex AI 正式演進為 **Gemini Enterprise Agent Platform**，定位為「代理編排作業系統」而非 API 服務；(b) **$750M 合作夥伴基金**，以「Google 前線工程師嵌入 Accenture/Deloitte/PwC/Capgemini 等大型系統整合商」方式加速落地；(c) 數據：Google Cloud 客戶中已有 **75% 在使用 AI 產品**，330 個客戶過去 12 個月各自消耗超過 1 兆 tokens。
- **Insight:** 這標誌著雲端 AI 的商業模式從「賣 API」轉向「賣代理基礎設施 + 嵌入服務」；Google 的做法是用諮詢公司的通路取代傳統 SaaS 銷售。對 MTK 而言，雲端 Agent 基礎設施愈成熟，edge agent（低延遲、離線、隱私）的需求差異化就愈清晰——但進入時機視窗可能只有 12-18 個月。
- **來源:** [Google Cloud Next '26 Recap](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/google-cloud-next-26-recap/), [Google Cloud $750M Fund](https://siliconangle.com/2026/04/22/google-cloud-invests-750m-fuel-agentic-enterprise-googlecloudnext/), [Gemini Enterprise Agent Platform](https://cloud.google.com/blog/products/ai-machine-learning/the-new-gemini-enterprise-one-platform-for-agent-development)

### 主軸 2: 模型迭代突破週邊界——GPT-5.5 / Opus 4.7 / Kimi K2.6 / DeepSeek V4 同週爆發
- **重要性:** ⭐⭐⭐⭐⭐
- **發生了什麼:** 4/20–4/24 五天內四大模型同週發布：**GPT-5.5**（Terminal-Bench 82.7%，agentic engine 定位）、**Claude Opus 4.7**（extended thinking + 抗諂媚設計）、**Kimi K2.6**（1.6T MoE 參數，300 子代理協作，OpenRouter 呼叫量第一位 297B tokens）、**DeepSeek V4-Flash**（輕量推論版，可在 Huawei Ascend NPU 執行）。此外 **Grok 4.3** 同期發布。五個 frontier 模型在一週內交錯上線是史上首次。
- **Insight:** 模型競賽的「比智力」階段已過，現在比的是「誰能最快把能力部署進代理框架」。Kimi K2.6 登 OpenRouter 呼叫量第一（超過 GPT-5.5）顯示中國開源生態在應用層採用速度超越預期；DeepSeek V4-Flash 驗證可跑 Ascend NPU 則是隱形的去NVIDIA化測試——這兩個訊號對 MTK NPU 架構的「兼容性策略」有重要含義。
- **來源:** [AI Models April 2026 Overview](https://renovateqr.com/blog/ai-models-april-2026), [Kimi K2.6 vs GPT-5.5 vs Opus 4.7 vs DeepSeek V4](https://www.cnblogs.com/qiniushanghai/p/19925673), [OpenAI GPT-5.5 vs Anthropic Opus 4.7](https://www.aicloudit.com/blog/ai/openai-gpt-5-5-anthropic-opus-4-7-release/)

### 主軸 3: NVIDIA N1 SoC 工程板曝光 + Computex 6/1 確認，MTK-NVIDIA AI PC 倒數計時
- **重要性:** ⭐⭐⭐⭐
- **發生了什麼:** NVIDIA N1 SoC 工程板實照曝光（Tom's Hardware 4/22 報導）：**20 Arm 核心**（MTK CPU IP）+ **6144 CUDA 核心**（Blackwell 架構）+ **128GB LPDDR5X**，定位高端 AI 工作負載；同時 Computex 主辦方 4/21 正式公布 **Jensen Huang 6/1 主講**，NVIDIA 完全取代 MTK 的 Computex 主角位置。大量出貨預估在 2026 下半年，Asus/Dell/Lenovo 三大 OEM 已確認在管線。
- **Insight:** 對 MTK 而言，N1 SoC 是「CPU IP 授權收入 + NVIDIA 生態入場券」，但品牌敘事（NVIDIA PC vs MTK PC）完全被 NVIDIA 掌控。MTK 在 N1 生態中的角色如同 Arm 之於高通——提供 IP 但不主導產品定義。這反而強化了 MTK 在 Google TPU 8i（inference ASIC，MTK 主導）上的戰略重要性，因為那是 MTK 能自主定義的雲端路線。
- **來源:** [NVIDIA N1 SoC 工程板](https://www.tomshardware.com/pc-components/motherboards/alleged-images-of-the-long-awaited-nvidia-n1-n1x-soc-surface-on-laptop-motherboard-board-features-128-gb-of-lpddr5x-memory-alongside-8-6-2-phase-vrm), [Computex 2026 NVIDIA Keynote](https://www.morningstar.com/news/pr-newswire/20260421hk39483/computex-2026-to-spotlight-nvidias-latest-ai-innovations-in-upcoming-keynote), [N1 大量出貨時程](https://www.tomshardware.com/pc-components/cpus/nvidia-and-mediateks-ai-cpu-may-not-see-mass-rollout-until-late-2026-asus-dell-and-lenovo-reportedly-developing-n1x-desktops-and-laptops)


### 主軸 4: Meta-Broadcom 1GW 2nm + Gemini Flash-Lite $0.25/M，自定義矽 + 低成本推論雙軌加速
- **重要性:** ⭐⭐⭐⭐
- **發生了什麼:** 本週兩件事放在一起看效果最強：(a) **Meta-Broadcom 確立超過 1GW 2nm MTIA 路線**（4/27 日報），每六個月一代路線圖至 MTIA 500，超大規模廠商「去 NVIDIA 化」從口號升格為多 GW 採購承諾；(b) **Google Gemini 3.1 Flash-Lite 以 $0.25/M tokens 發布**，API 推論定價進入「分錢計價」時代，推論成本曲線持續垂直下降。兩件事的共同含義：算力特化（自定義矽）與成本崩潰（$0.25/M）同步發生，雲端 AI 的單位經濟學正在重構。
- **Insight:** 當雲端推論成本趨近免費，edge inference 的差異化必須全面轉向三個雲端無法取代的維度：**低延遲（< 10ms）、本地隱私（資料不離裝置）、離線可靠性**。MTK edge AI 的 positioning 敘事窗口因為這兩個訊號而反而更清晰——但需要在 2026 Q3 前重新定義產品敘事，否則市場認知會持續以「跑不了大模型」來框架 edge chip。
- **來源:** [Meta MTIA 四代路線](https://ai.meta.com/blog/meta-mtia-scale-ai-chips-for-billions/), [Gemini 3.1 Flash-Lite 定價](https://blog.google/products/gemini/gemini-3-flash-lite/)

### 主軸 5: 中國反制升溫——限制接受美投資、自承晶片差距 5-10 年，但 Kimi K2.6 全球用量稱霸
- **重要性:** ⭐⭐⭐⭐
- **發生了什麼:** 三件中國相關新聞同週交叉：(a) **中國擬限制科技公司接受美投資**（需政府核准），中國 AI 生態圈加速封閉化；(b) **中國半導體業者公開承認 AI 晶片技術落後全球 5-10 年**（CNA 4/10 報導），且 AI 需求爆發遠超設備/人力產能；(c) **但 Kimi K2.6 在 OpenRouter 全球呼叫量超越 GPT-5.5，成為第一**（297B tokens/月）——軟體應用層能力已解耦於硬體差距。
- **Insight:** 這是典型的「硬體牆 + 軟體突圍」格局：中國在晶片製造上被卡死，但在模型架構創新（DeepSeek MoE 效率、Kimi 多代理設計）上仍保持全球競爭力。對 MTK 而言，這意味著 NPU 的「模型兼容性」（特別是 DeepSeek/Kimi 的量化版本）將成為中國大市場的重要採購評估標準，而非只看 benchmark 分數。
- **來源:** [中國擬限制接受美投資](https://www.cna.com.tw/news/aopl/202604240325.aspx), [中國業者承認晶片落後 5-10 年](https://techorange.com/2026/04/10/china-chip-industry-ai-demand/), [AI 模型四強對比評測](https://www.cnblogs.com/qiniushanghai/p/19925673)

## 4️⃣ ⚠️ 本週 2 個最重要弱訊號

### 弱訊號 1: Kimi K2.6 在 OpenRouter 全球呼叫量登第一（297B tokens），300 子代理協作設計
- **為什麼你不該略過:** OpenRouter 是全球最廣泛的第三方 LLM API 路由平台，Kimi K2.6 在此超越 GPT-5.5 位居第一，代表的不只是中國模型的崛起，而是「MoE 架構 + 超大上下文 + 多代理協作設計」的組合已被全球開發者採納為生產基礎設施。這個架構若成為開源 agentic AI 的事實標準，將直接影響 NPU 在多代理任務切換時的計算圖設計需求。DeepSeek V4 已驗證可跑 Huawei Ascend NPU，代表 MTK NPU 的「非 NVIDIA 兼容性」測試迫在眉睫。
- **追蹤指標:** Kimi K2.6 月呼叫量（OpenRouter 排行）；DeepSeek V4-Flash INT4 量化版本在 Dimensity 9400 的 benchmark；MTK 是否公開 Kimi/DeepSeek 模型的 NPU 優化計畫
- **來源:** [Kimi K2.6 vs 四大模型評測](https://www.cnblogs.com/qiniushanghai/p/19925673), [DeepSeek V4 技術細節](https://www.163.com/dy/article/KRA8BR420511ABV6.html)

### 弱訊號 2: Google 以 $750M 將工程師嵌入諮詢公司——雲端 AI 轉向「服務化」模式
- **為什麼你不該略過:** Google 的 $750M 不是補貼，而是派遣工程師進駐 Accenture/Deloitte/PwC 等大廠，**把 AI 部署能力融入諮詢服務**。這個模式若成功，將重新定義企業 AI 採購流程：客戶不再直接買 API，而是透過諮詢合約取得「AI 轉型服務 + Google Cloud 使用權」的捆綁包。這對台灣的 AI 系統整合商（SI）是重大衝擊——Google 正在直接競爭其服務通路；同時對 MTK 而言，若 enterprise 大客戶的 AI 採購全部走 Google/系統整合商通路，edge AI 的 B2B 銷售策略需要重新思考。
- **追蹤指標:** Google Cloud 合作夥伴基金的第一批成功案例（Accenture/Deloitte 的 MTR 或製造業落地）；Microsoft 是否跟進類似的 Copilot 服務化模型；台灣 SI 業者對此模式的因應策略
- **來源:** [Google Cloud $750M](https://siliconangle.com/2026/04/22/google-cloud-invests-750m-fuel-agentic-enterprise-googlecloudnext/), [Google Cloud Next '26 7 Highlights](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/google-cloud-next-26-recap/)

## 5️⃣ 🎤 Monday Talking Points + 部門策略

### Talking Point 1: "Agent 基礎設施大戰開打——我們的 edge agent 差異化在哪裡？"
> "Google 上週以 $750M 奠定雲端 Agentic 基礎設施，Vertex AI 正式升格為代理作業系統。但有一件事 Google 做不到：在 < 10ms 延遲、離線、無資料上傳的場景下執行代理任務。這正是 MTK edge AI 的防守陣地——問題是我們的 agent runtime 是否已就位？"

**背後的部門策略:** 雲端 agent 與 edge agent 不是零和競爭，而是一個垂直堆疊。雲端做複雜推理，edge 做即時反應。MTK 的策略應該是找出哪些企業場景（工廠品管、醫療設備、汽車 ADAS）需要 cloud-edge 混合代理協作，先建立這些場景的參考設計（reference design），而非與 Google 正面競爭代理平台。

### Talking Point 2: "Kimi K2.6 登全球呼叫量第一——MTK NPU 對中國開源模型的兼容性在哪裡？"
> "Kimi K2.6 這週在全球 OpenRouter 平台超越 GPT-5.5，成為呼叫量第一。DeepSeek V4 已確認可跑 Huawei Ascend NPU。問題是：我們的 NPU 能跑這些中國開源模型的 INT4/INT8 量化版本嗎？如果不能，我們在中國大市場的 edge AI 競爭力就需要重新評估。"

**背後的部門策略:** 中國 AI 生態已走向「軟體能力解耦硬體差距」的路徑——模型軟體極強，但晶片製造落後 5-10 年。MTK 要在中國市場贏得 edge AI 採用，關鍵是「模型兼容性認證計畫」：公開聲明支援 DeepSeek V4-Flash / Kimi K2.6 量化版本在 Dimensity 系列上的最佳化執行，比 benchmark 分數更能打動中國 OEM 採購。

### Talking Point 3-5: 其他本週可帶入的討論點

- **TP3 — N1 SoC 競品分析視窗打開:** "NVIDIA 6/1 Computex 前，我們是否有 N1 SoC 的完整競品分析框架？20 Arm 核 + 6144 CUDA + 128GB LPDDR5X 的目標市場是高端創作者筆電，Qualcomm Snapdragon X Elite 是直接競品，MTK 在這個賽道上的定位是什麼？"

- **TP4 — 推論成本崩潰 + edge AI 再定位:** "Gemini Flash-Lite 現在 $0.25/M tokens，API 成本幾乎免費。如果雲端推論這麼便宜，客戶憑什麼多花錢買 edge AI 晶片？這個問題 2026 Q3 前必須有清晰的答案，否則 edge AI 的銷售陷入結構性困難。"

- **TP5 — 中國 AI 封閉化對台灣的衝擊:** "中國擬限制科技公司接受美投資，AI 生態圈加速封閉化。如果中國 AI 開源社群（DeepSeek、Kimi）與全球生態脫鉤，MTK 在兩個市場（中國 vs 非中國）的 NPU 策略是否需要分開設計？"
